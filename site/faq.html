FAQ & troubleshooting

Answers to the most common setup and troubleshooting questions. For the full walkthrough, see the user guide.

The faces don't show up in Football Manager after I ran it. What now?

Football Manager caches portraits, so it keeps showing the old (blank) faces until you clear that cache. In FM, go to Preferences → Interface and choose Clear Cache and Reload Skin, or simply restart Football Manager.

Also double-check that your face pack folder (which contains config.xml) sits under the graphics folder of the same FM installation you exported the newgen list from, and that you picked the matching Football Manager version in FM NewGen Faces. See Make FM show the faces.

It says "no ethnic subfolders found" for my face pack folder. What's wrong?

FM NewGen Faces expects the folder you point it at to directly contain the 14 ethnic subfolders: African, Asian, Caucasian, Central European, EECA, Italmed, MENA, MESA, SAMed, Scandinavian, Seasian, South American, SpanMed, YugoGreek.

If your download extracted into an extra wrapper folder, or your pack nests those 14 folders one level deeper, point the face pack field at the folder that directly contains them, not its parent or a subfolder. See Install a face pack.

Some players show up as an unknown/unmapped nation. What do I do?

A nation code with no entry in the built-in table shows those players as unmapped instead of blocking the run. Click Resolve now on the setup checklist (or Nation overrides… on the Assign faces card) to pick an ethnic group for each unknown code; it's saved as an override for that profile and applied on every future run. A single unknown nation never stops the rest of the run.

See Nation overrides for the TOML import/export format.

My newgen.rtf isn't detected, or only some players show up.

The file must be saved as newgen.rtf directly inside the face pack folder – the app watches that folder and picks it up automatically; if you saved it elsewhere, browse to it manually.

If only some players appear, check the setup checklist for a malformed-row count: FM's print-to-file export can produce a truncated last line, which FM NewGen Faces skips and reports rather than aborting the whole import. Re-exporting (Ctrl+A, then Ctrl+P) usually fixes a truncated file. See Export the newgen list from FM.

The app says it can't find my Football Manager installation.

Automatic detection looks in your Documents folder (and OneDrive, or Steam Proton/Heroic prefixes on Linux). If your FM install lives somewhere else, choose Custom location in the first-run wizard, or set the face pack folder, config.xml path and Football Manager version by hand in the Advanced section – everything works the same, you just also need to install the bundled view and filter into that installation's views and filters folders yourself.

Can config.xml live on a different drive than my face pack?

config.xml has to sit inside the graphics folder of the Football Manager installation you want the faces to appear in, and the image paths it writes are relative to config.xml's own folder. The simplest and default setup keeps config.xml directly inside the face pack folder, which is itself under …/Football Manager 2024/graphics/. If you move config.xml elsewhere, keep the face pack in the same relative position to it, otherwise FM won't resolve the portrait paths. The app checks this for you: if config.xml and the face pack are on different drives, the setup check reports it before you run.

Where is the log file, and how do I report a bug?

Toggle the log panel in the app with Ctrl+L, or find fm-newgen-faces.log in the app's config directory (~/.config/fm-newgen-faces on Linux, ~/Library/Application Support/fm-newgen-faces on macOS, %AppData%\fm-newgen-faces on Windows).

To report a problem, use Report a bug… in the settings menu: it collects your profiles, the setup checklist and the log tail with your home directory and username redacted, and opens a prefilled GitHub issue you can review before submitting.

Is my data sent anywhere?

No. FM NewGen Faces works entirely offline except for one thing: an optional check against api.github.com for a newer release. Nothing about your save, your face pack or your files is uploaded anywhere. A bug report is only created locally and only sent if you click Open GitHub issue yourself, with your home directory and OS username already redacted from it.

Which Football Manager versions are supported?

FM20 through FM24. FM24 introduced the r-<id> portrait naming inside config.xml; FM20–FM23 use the bare newgen ID. Pick the matching version in FM NewGen Faces (it's usually detected automatically from your face pack's path) and it writes the correct format for you.

I'm migrating from Jaqen NewGen Tool (1.x). Do I lose my profiles?

No. FM NewGen Faces is the v2 rewrite of Jaqen NewGen Tool, and it migrates your legacy 1.x profiles automatically, once, the first time you start it – no manual export/import needed. The tutorial video was recorded for the 1.x interface, so some screens look different, but the core workflow (face pack → newgen export → assign) is the same.
