Command line reference

FM NewGen Faces has a full headless CLI alongside the GUI, so you can script a new-season run, wire it into a batch file, or fetch machine-readable output. Running the binary with no arguments launches the desktop app.

Global flags

These apply to every subcommand (place them before the subcommand name):

FlagDescription
--config-dir <dir>Profile and backup directory. Default: the OS user config directory (see Undo and backups).
--lang <code>UI language code, e.g. en, de.

Commands

  • gui
  • version
  • profiles
  • detect
  • check
  • assign
  • restore

fm-newgen-faces [gui]

Launches the desktop application. This is also what running the binary with no subcommand does, so fm-newgen-faces and fm-newgen-faces gui are equivalent.

fm-newgen-faces
fm-newgen-faces gui

fm-newgen-faces version

Prints the app name and version and exits.

$ fm-newgen-faces version
FM NewGen Faces 2.0.0

fm-newgen-faces profiles

Lists all profiles (slug, name, FM version, face pack folder, game path). With no profiles yet, it says so.

fm-newgen-faces profiles

fm-newgen-faces profiles create <name>

FlagDescription
--game <path>FM install path this profile belongs to.
 
fm-newgen-faces profiles create "FM 2024" --game "/home/alex/Documents/Sports Interactive/Football Manager 2024"

fm-newgen-faces profiles show <slug>

Prints that profile's settings as JSON – handy for inspecting or diffing a profile in a script.

fm-newgen-faces profiles show fm-2024

fm-newgen-faces profiles delete <slug>

fm-newgen-faces profiles delete fm-2024

fm-newgen-faces detect

Lists Football Manager installations found on this machine (name, version, base path, source: Documents, OneDrive, Steam Proton, Heroic or custom).

FlagDescription
--install-viewsAlso install the bundled SCRIPT FACES view and newgen filter into every installation found.
 
# List installations
fm-newgen-faces detect

# List installations and (re)install the view/filter into all of them
fm-newgen-faces detect --install-views

fm-newgen-faces check

Validates the current profile's setup: face pack folder counts per ethnic group, missing folders, the RTF export's player/unmapped/malformed counts, and the existing config.xml mapping count. Exits with status 1 if any problem is found (useful for CI-style checks before a scheduled run).

FlagDescription
--profile <name|slug>Profile to check. Default: last used, or the only profile.
--pack <dir>Face pack folder (overrides the profile value).
--rtf <file>Newgen export (RTF) path (overrides the profile value).
--config <file>config.xml path (overrides the profile value).
--fm <year>Football Manager version, e.g. 2024 (overrides the profile value).
 
# Check a saved profile
fm-newgen-faces check --profile "FM 2024"

# Check a stand-alone setup with explicit paths
fm-newgen-faces check --pack ./faces --rtf ./faces/newgen.rtf --config ./faces/config.xml --fm 2024

fm-newgen-faces assign

Builds the plan and, unless --dry-run is given, writes config.xml (backing up the previous file first, unless --no-backup is given). Exits with status 2 if any player was skipped.

FlagDescription
--profile <name|slug>Profile to use. Default: last used, or the only profile.
--pack <dir>Face pack folder (overrides the profile value).
--rtf <file>Newgen export (RTF) path (overrides the profile value).
--config <file>config.xml path (overrides the profile value).
--fm <year>Football Manager version, e.g. 2024 (overrides the profile value).
--dry-runShow the plan without writing anything.
--preserve / --no-preserveKeep existing newgen mappings, or reassign every player including already-mapped ones. Default comes from the profile/settings.
--duplicates / --no-duplicatesAllow the same image for several players, or never reuse an image already mapped in config.xml. Default comes from the profile/settings.
--seed <int>Random seed for reproducible runs (0 = random).
--no-backupDo not keep a backup of the previous config.xml.
--jsonPrint the plan and result as one JSON document instead of tables.
--yes, -ySkip the confirmation prompt (needed for non-interactive/scripted runs).
--override CODE=GroupNation override for this run only, e.g. --override AFG=MESA. Repeatable.

Examples

Scripting a new-season run (non-interactive, so it can run unattended or in a scheduled task):

fm-newgen-faces assign --profile "FM 2024" --yes

JSON output for parsing the plan/result in another tool:

fm-newgen-faces assign --profile "FM 2024" --dry-run --json

Stand-alone run with explicit paths, no profile:

fm-newgen-faces assign \
  --pack ./faces --rtf ./faces/newgen.rtf \
  --config ./faces/config.xml --fm 2024 --yes

Resolve an unknown nation and reassign everyone in one go:

fm-newgen-faces assign --profile "FM 2024" \
  --override AFG=MESA --no-preserve --yes

fm-newgen-faces restore

Lists or restores timestamped config.xml backups. Requires at least one of --list, --to or --latest. The current config.xml is itself backed up to <config.xml>.before-restore before a restore.

FlagDescription
--profile <name|slug>Profile whose config.xml to use.
--config <file>config.xml path, used instead of --profile.
--listList available backups for the resolved config.xml.
--to <backup>Restore from this specific backup file.
--latestRestore from the most recent backup.

Examples

# List backups for a profile
fm-newgen-faces restore --profile "FM 2024" --list

# Undo the last run
fm-newgen-faces restore --profile "FM 2024" --latest

# Restore a specific backup by path
fm-newgen-faces restore --config ./faces/config.xml --to ./faces/config.xml.2026-09-01-120000

Exit codes

CodeMeaning
0Success.
1An error occurred, or check found problems.
2An assign run completed but one or more players were skipped.
